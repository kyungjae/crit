## 요약

- ChatCut은 원하는 편집을 자연어로 설명하면 영상의 내용을 파악하고 실제 타임라인에 작업을 반영하는 AI 영상 편집기임.
- 영상 전체를 한 번에 생성하기보다, 기존 영상을 보고 하이라이트를 찾고 반복 테이크와 필러를 정리해 첫 번째 편집본을 만드는 데 초점을 둠.
- 트랜스크립트 편집, B-roll, 챕터 카드, 차트와 타이포그래피 애니메이션, 음악과 음성 생성 기능을 한 작업 공간에서 연결함.
- 공식 홈페이지는 브라우저에서 사용하거나 ChatGPT·Claude 같은 에이전트 도구와 함께 사용할 수 있다고 설명함.

## 프롬프트로 영상을 편집함

ChatCut의 공식 홈페이지 제목은 **“Your AI Video Editing Assistant”**임. 사용자가 원하는 작업을 설명하면 ChatCut이 필요한 방법을 판단하고 작업한다고 소개함.

예를 들면 다음과 같은 편집을 요청할 수 있음.

- 영상에서 하이라이트 찾기
- 반복되는 테이크 정리하기
- 필러 단어와 불필요한 공백 지우기
- talking-head 영상에 B-roll 넣기
- 챕터 카드와 강조 효과 추가하기
- 차트, 타임라인, 키워드 애니메이션 만들기

홈페이지의 데모는 프롬프트 입력창, 영상 미리보기, 영상·그래픽·음악 트랙이 있는 타임라인을 함께 보여줌. AI에게 지시한 결과가 채팅 답변으로 끝나는 것이 아니라 편집 작업으로 이어지는 구조임.

## 전문가처럼 첫 번째 편집본을 만듦

ChatCut은 에이전트가 영상을 보고 각 클립의 내용을 이해한 뒤, 의미가 통하는 순서로 배치한다고 설명함.

기존의 템플릿형 영상 도구가 원본 영상에 정해진 디자인과 효과를 입히는 방식이라면, ChatCut은 원본을 편집하는 쪽에 가까움. 홈페이지는 이를 **“prompt-based video editing done properly”**라고 표현함.

핵심으로 내세우는 작업은 다음과 같음.

- 영상의 중요한 장면 찾기
- 반복되는 테이크 자르기
- 실제로 사용할 수 있는 첫 번째 편집본 만들기
- 템플릿을 덮어씌우는 대신 원본 영상의 흐름에 맞춰 편집하기

## 문장을 고치듯 영상을 편집함

ChatCut은 말하는 영상의 트랜스크립트를 함께 보여줌. 트랜스크립트에는 다음과 같은 필러 단어와 반복적인 표현이 포함되어 있음.

> So, um, today I want to talk about…

사용자는 트랜스크립트에서 문장을 지우거나, “Clean up all the filler words”처럼 원하는 작업을 프롬프트로 요청할 수 있음. 그러면 해당 내용이 영상 편집과 연결됨.

이 방식은 타임라인에서 짧은 침묵을 하나씩 찾아 자르는 대신, 먼저 내용과 문장을 기준으로 편집할 수 있게 함. 인터뷰, 강의, 제품 설명, 크리에이터 영상처럼 사람이 말하는 장면이 많은 콘텐츠에 적합한 구조임.

## 한 문장으로 모션 그래픽을 만듦

ChatCut은 모션 그래픽도 프롬프트로 만들 수 있다고 설명함.

- 챕터 카드
- 막대 그래프와 파이 차트
- 세로 타임라인
- 키워드 타이핑 애니메이션
- 텍스트 강조 효과

공식 홈페이지의 예시는 “거친 크리에이터 영상을 선명한 챕터, 차트와 강조된 화면으로 바꿔달라”는 요청임. After Effects를 열고 키프레임을 직접 만드는 대신, 원하는 애니메이션을 문장으로 설명해 타임라인에 추가하는 방식임.

## 생성 기능은 편집에 필요한 재료를 채우는 데 사용함

ChatCut은 영상 편집 외에도 여러 생성 기능을 제공함.

- 영상 생성
- 이미지 생성
- AI 음악
- AI 음성
- 모션 그래픽
- 자동 캡션

필요한 B-roll이나 설명용 이미지가 없을 때 작업 흐름 안에서 생성하고, 결과물을 타임라인에 추가하는 방식임. 영상 전체를 처음부터 생성하는 서비스라기보다, 촬영한 영상을 편집하는 과정에서 비어 있는 재료를 채우는 방향에 가까움.

2026년 8월 3일 공식 가격 페이지를 확인한 기준으로 무료 플랜이 있고, 유료 플랜은 월 결제 기준 100크레딧에 월 25달러부터 시작함. 연간 결제는 100크레딧 기준 월 21달러로 표시됨. 상위 플랜으로는 월 400크레딧·월 100달러 옵션이 보임.

- Seedance 2.0 영상 최대 166초

작업과 모델에 따라 크레딧 사용량이 달라지는 구조임. 따라서 월 구독료만으로 실제 제작 비용을 계산하기는 어려움. 생성 결과를 다시 고칠 때 크레딧이 필요한지, 일반적인 컷 편집과 캡션 작업에 어떤 제한이 있는지도 확인해야 함.

## crit의 관점

ChatCut은 AI 영상 생성기보다 AI 편집기에 가까운 방향을 택함. 이 차이는 작지 않음. 대부분의 영상 제작에서 시간이 많이 드는 일은 영상을 아무것도 없는 상태에서 만드는 것보다, 이미 촬영한 영상을 보고 무엇을 남기고 무엇을 버릴지 결정하는 일이기 때문임.

자연어로 편집을 지시하고 결과를 타임라인에서 확인할 수 있다는 점은 좋음. AI의 작업이 최종 영상 파일 속으로 사라지지 않고, 사람이 다시 볼 수 있는 편집 구조로 남음.

다만 타임라인에 결과가 보인다고 해서 편집 판단까지 투명해지는 것은 아님. AI가 왜 이 장면을 하이라이트로 골랐는지, 왜 이 침묵을 삭제했는지, 어떤 기준으로 B-roll을 선택했는지는 여전히 확인해야 함.

특히 회사 영상이나 브랜드 콘텐츠에서는 고유명사·숫자·전문용어를 잘못 인식하거나, 문맥상 필요한 침묵을 삭제하거나, 브랜드와 맞지 않는 이미지를 선택하는 문제가 생길 수 있음.

### 좋게 볼 점

- 자연어 지시가 실제 멀티트랙 타임라인 작업으로 이어짐.
- 트랜스크립트 편집과 영상·오디오 편집이 연결되어 있음.
- 하이라이트와 반복 테이크를 정리하는 첫 번째 편집에 사용 목적이 분명함.
- 모션 그래픽과 생성 기능을 별도 도구로 옮기지 않고 편집 흐름 안에서 사용할 수 있음.

### 남는 한계

- 공식 페이지마다 캡션 언어와 스타일 수치가 다르게 표시됨.
- 생성 기능별 크레딧 비용이 달라 실제 제작비 예측이 쉽지 않음.
- 실제 편집 품질과 원본 영상 처리 방식은 직접 사용해봐야 함.
- 생성된 영상·이미지·음악의 권리 범위와 데이터 보존 정책은 추가 확인이 필요함.
