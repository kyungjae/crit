## 핵심 원칙: 주니어에게 브리핑하듯

AI에게 요청하는 것은 주니어 디자이너에게 업무를 브리핑하는 것과 같습니다.
맥락, 제약, 기대 결과를 명확히 줄수록 결과가 좋아집니다.

## 패턴 4가지

### 1. 역할 + 맥락

```
너는 핀테크 앱의 프로덕트 디자이너야.
40-50대 사용자가 주 타깃이고, 신뢰감이 최우선 가치야.
```

### 2. 제약 조건 명시

```
버튼 카피를 5개 제안해줘. 단, 8자 이내, 존댓말, '무료'라는 단어 금지.
```

### 3. 좋은 예 / 나쁜 예 제공

원하는 톤의 예시 2-3개와 피하고 싶은 예시를 함께 주세요.

### 4. 반복 개선 요청

첫 결과에서 끝내지 말고 "2번 방향으로 더 과감하게"처럼 방향을 조정하세요.

## 흔한 실수

- 한 프롬프트에 여러 작업을 섞기 → 하나씩 나눠 요청
- 결과 포맷을 지정하지 않기 → "표로", "불릿 5개로" 등 명시
