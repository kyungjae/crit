Palmier Pro는 “AI 영상 생성기”라기보다 **AI가 조작할 수 있는 영상 편집기**에 가깝습니다. GitHub README의 한 문장은 방향을 정확히 보여줍니다. “You and your agent can generate and edit videos together inside the timeline.” 사람이 타임라인에서 편집하고, 에이전트도 같은 타임라인을 읽고 고칠 수 있다는 뜻입니다.

이 차이가 중요합니다. Runway나 Higgsfield 같은 생성 플랫폼은 클립을 만듭니다. 하지만 실제 영상 제작은 클립을 만드는 순간이 아니라, 좋은 컷을 고르고, 이어 붙이고, 다시 생성하고, 교체하고, 자막과 효과를 조정하는 반복 안에서 완성됩니다. Palmier Pro가 겨냥하는 문제는 바로 이 반복입니다.

![Palmier Pro UI — 생성과 편집이 같은 타임라인 안에 들어온다](https://raw.githubusercontent.com/palmier-io/palmier-pro/main/assets/palmier-ui.png "Palmier Pro UI — 공식 GitHub README 이미지")

## 생성 버튼이 아니라 타임라인 안의 AI

Palmier Pro는 macOS용 오픈소스 영상 편집기입니다. Swift로 처음부터 만들었고, 방향성은 Premiere Pro에 가깝다고 설명합니다. 다만 AI를 플러그인처럼 붙이는 것이 아니라 편집 워크플로 자체에 넣습니다. README 기준으로 Seedance, Kling, Nano Banana Pro 같은 모델을 타임라인 편집기 안에서 호출해 영상과 이미지를 생성할 수 있습니다.

FAQ에는 이 제품을 만든 이유가 더 솔직하게 적혀 있습니다. Palmier 팀은 YC 기업들의 AI 런칭 영상을 만들면서, 생성형 영상 도구와 편집기가 분리되어 있는 것이 가장 큰 병목이었다고 설명합니다. 웹에서 생성하고, 다운로드하고, 편집기에 가져오고, 마음에 들지 않으면 다시 생성하고, 다시 가져오는 루프가 반복됩니다. 버전별 파일과 프롬프트, 참고 이미지, 좋은 테이크와 실패한 테이크가 흩어지기 시작하면 프로젝트는 금방 관리하기 어려워집니다.

Palmier Pro의 대답은 “영상 편집기를 단일 진실 공급원으로 만들자”에 가깝습니다. 생성 결과도, 편집 상태도, 에이전트가 참고해야 할 맥락도 한 프로젝트 안에 두려는 시도입니다.

## MCP가 붙으면서 편집기는 ‘조작 가능한 앱’이 됩니다

Palmier Pro의 흥미로운 점은 MCP 서버입니다. 앱이 열려 있으면 `http://127.0.0.1:19789/mcp`에서 MCP 서버를 노출하고, Claude Code, Codex, Cursor, Claude Desktop을 연결할 수 있습니다. 즉 채팅창의 AI가 단순히 편집 방법을 설명하는 것이 아니라, 프로젝트 타임라인을 읽고 실제 편집 작업을 요청받을 수 있습니다.

YC 소개 페이지에서도 Palmier는 Claude와 Codex가 타임라인을 직접 편집할 수 있다고 설명합니다. 가능한 작업의 예시는 컷 정리, 순서 변경, 영상 생성, 첫 번째 러프컷 만들기, 긴 영상에서 핵심 장면 찾기, 캡션과 파일 정리 같은 반복 업무입니다.

이건 디자인 도구 관점에서도 중요한 신호입니다. 지금까지 많은 AI 디자인 도구는 “프롬프트를 넣으면 결과물을 만들어준다”에 집중했습니다. Palmier Pro는 조금 다릅니다. 결과물을 한 번에 뽑는 것이 아니라, 사람이 계속 판단하는 작업판을 AI도 함께 조작하게 만듭니다. 도구가 채팅창 바깥의 실제 편집 상태를 이해하고 변경할 수 있어야 한다는 쪽입니다.

## 오픈소스지만, 생성형 AI는 완전히 열린 것은 아닙니다

현재 GitHub 기준 Palmier Pro는 2026년 4월 공개된 저장소이고, 약 1.27만 개의 스타와 900개 이상의 포크를 모았습니다. 라이선스는 GPLv3입니다. 최신 릴리즈에는 macOS용 DMG가 올라와 있고, README는 Apple Silicon 기반 macOS 26 Tahoe를 요구한다고 밝힙니다.

다만 “오픈소스 영상 편집기”라는 표현은 정확히 읽어야 합니다. FAQ에 따르면 영상 편집기 자체, MCP 서버, 에이전트 채팅은 오픈소스지만, 생성형 AI 처리 부분은 비공개입니다. 편집기는 무료로 쓸 수 있고 로그인 없이 다운로드할 수 있지만, 생성형 AI 기능은 로그인과 구독이 필요합니다.

이 구조는 현실적입니다. 영상 편집기의 코어를 공개해 커뮤니티와 신뢰를 만들고, 비용이 큰 생성 모델 호출과 프로덕트 경험은 유료 레이어로 남깁니다. 동시에 GPLv3라는 라이선스는 기업이나 다른 제품이 이 코드를 직접 가져다 쓸 때 고려해야 할 조건을 만듭니다.

## 아직은 ‘Premiere 대체재’보다 실험적인 새 축에 가깝다

Palmier 팀도 기능 격차를 숨기지 않습니다. FAQ에는 아직 전환 효과, 마스킹, 그래픽 기능이 부족하다고 적혀 있습니다. “AI 기능을 빼면 꽤 기본적인 영상 편집기”라고도 말합니다. 그래서 지금 Palmier Pro를 Premiere Pro나 CapCut의 완전한 대체재로 읽으면 과장입니다.

오히려 지금 봐야 할 것은 완성도보다 방향입니다. Palmier Pro는 영상 편집의 중심을 “생성 모델”에서 “프로젝트 상태를 가진 편집 환경”으로 다시 옮깁니다. AI가 컷을 만들 수 있어도, 결국 제작자는 어떤 컷을 남길지, 어느 리듬이 맞는지, 메시지가 어디서 무너지는지 판단해야 합니다. 그 판단이 일어나는 장소는 여전히 타임라인입니다.

## crit의 관점: 좋은 AI 도구는 사람의 판단 위치를 없애지 않습니다

Palmier Pro가 흥미로운 이유는 AI가 사람을 대체한다고 말하지 않아서입니다. FAQ에서 팀은 에이전트가 인간의 창의성을 복제할 수는 없지만, 영상 생성과 편집 과정에는 AI가 도울 수 있는 수많은 수작업이 있다고 씁니다. 이 문장이 제품의 핵심에 가깝습니다.

좋게 볼 점은 Palmier Pro가 AI를 결과물 공장으로만 다루지 않는다는 점입니다. 생성, 선택, 교체, 정리, 편집, 내보내기가 이어지는 실제 제작 루프 안으로 AI를 넣습니다. 디자이너와 영상 제작자에게 필요한 것은 “멋진 클립 하나”가 아니라, 실패한 시안과 성공한 시안을 같은 문맥에서 비교하고 다음 판단으로 넘어갈 수 있는 작업 환경입니다.

아쉬운 점은 이 접근이 더 어려운 제품 문제를 떠안는다는 데 있습니다. 에이전트가 타임라인을 조작하려면 편집 상태, 클립 간 관계, 프롬프트 이력, 모델별 결과, 사용자의 취향을 모두 안정적으로 표현해야 합니다. 잘못 편집했을 때 되돌리기와 검증도 중요합니다. AI가 편집기를 만질 수 있다는 것만으로는 부족하고, 사람이 그 변경을 빠르게 이해하고 승인할 수 있어야 합니다.

그래서 Palmier Pro는 영상 도구 하나의 소식이라기보다 디자인 도구 전반의 질문처럼 보입니다. 앞으로의 도구는 AI가 결과물을 대신 만들어주는 방향으로 갈까요, 아니면 사람이 판단하는 작업판을 AI도 함께 읽고 조작하는 방향으로 갈까요. Palmier Pro는 후자에 꽤 선명하게 베팅하고 있습니다.
